# Package index

## Top-Level Functions

These are entry-level functions that try to be easy to use by automating
things.

- [`lingmatch()`](https://miserman.github.io/lingmatch/reference/lingmatch.md)
  : Linguistic Matching and Accommodation
- [`lma_process()`](https://miserman.github.io/lingmatch/reference/lma_process.md)
  : Process Text
- [`lma_meta()`](https://miserman.github.io/lingmatch/reference/lma_meta.md)
  : Calculate Text-Based Metastatistics

## Component Functions

These are the build blocks of the top-level functions.

- [`lma_dtm()`](https://miserman.github.io/lingmatch/reference/lma_dtm.md)
  : Document-Term Matrix Creation
- [`lma_weight()`](https://miserman.github.io/lingmatch/reference/lma_weight.md)
  : Document-Term Matrix Weighting
- [`lma_lspace()`](https://miserman.github.io/lingmatch/reference/lma_lspace.md)
  : Latent Semantic Space (Embeddings) Operations
- [`lma_termcat()`](https://miserman.github.io/lingmatch/reference/lma_termcat.md)
  : Document-Term Matrix Categorization
- [`lma_patcat()`](https://miserman.github.io/lingmatch/reference/lma_patcat.md)
  : Categorize Texts
- [`lma_simets()`](https://miserman.github.io/lingmatch/reference/lma_simets.md)
  : Similarity Calculations
